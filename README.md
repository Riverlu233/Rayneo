## 最新更新（2026-09-01）

### ArUco 实体五子棋棋盘定位

* 新增 `Rayneo_Demo/aruco_board_recognition.py`：使用 `DICT_4X4_50` 的四个 ArUco 标签（ID 0/1/2/3）确定棋盘四个外层交叉点，并通过单应变换完成透视校正；当前 Demo 不再依赖原角点 YOLO 模型。
* 新增 `generate_aruco_tags.py` 及 6 cm A4 黑白打印标签资源。标签整体旋转不影响检测；每个标签朝向棋盘中心的内角需与对应棋盘外层交叉点对齐。
* `GomokuAgent` 已切换到新的定位器，但旧 `board_recognition.py` 保留，便于回退和继续做论文复现实验。

### 棋子识别与展示稳定性

* 透视校正后的棋盘以纯灰度、YOLO X1 原生 `640` 输入尺寸进行推理；保留 CUDA 自动选择与延迟日志。
* 针对黄色实体棋盘补充交叉点暗度探测，仅补回 YOLO 漏检的黑子；白子使用短暂保持机制抑制单帧闪烁。
* PC 画面新增 ArUco 调试叠加：绿色四边形表示棋盘已锁定，缺少标签时会提示所需的标签 ID。
* 推荐落子坐标统一按棋盘交叉点计算，而非格子中心。

### 采集与泛化路线

ArUco 标签当前用于实时标定和自动产生棋盘四角真值。后续可用这些真值训练不含标签的四角/姿态模型；标签不应作为最终部署依赖。

本项目旨在为Rayneo智能眼镜开发一个具有简单功能的应用。

## 最新更新 (8月31日)

### 1. 端到端延迟基准与 GPU 推理
* **分段延迟日志**：在眼镜端和 PC 端接收链路中补充了格式转换、JPEG 编解码、队列等待、OpenCV 预处理、YOLO 预处理/模型调用/DataFrame 后处理等时间探针，用于区分网络积压、CPU 处理和模型推理瓶颈。
* **GPU 自动选择**：PC 端 YOLO 运行时优先使用可用 CUDA 设备，并在基准计时前同步 CUDA，避免异步调用造成模型推理时间失真；无 CUDA 时自动回退 CPU。
* **实时链路减负**：默认关闭同步落盘采集，避免 JPEG 写盘影响实时帧率；保留可选的数据集采集能力。

### 2. 实体棋盘识别诊断
* **论文链路核对**：引入 GO_CORNER、GO_PIECEX1、GO_PIECEX2 的离线验证，并核对原 YOLO-GO 推理的 `640` letterbox 输入、灰度化和直方图均衡处理位置。
* **角点诊断工具**：新增 `Rayneo_Demo/diagnose_board_corners.py`，可对图像比较黄色区域和边缘四边形候选，输出角点标注、透视矫正图和掩码，供真实棋盘数据采集前验证。
* **当前结论**：真实黄色棋盘上，边缘闭合与凸四边形拟合可稳定得到 Test4 的棋盘四角；透视矫正后，X1 在纯灰度/彩色、`640` 输入下可恢复棋子检测。复杂第一视角仍需后续采集数据并训练轻量四角定位模型。

### 3. 眼镜端界面与 SDK 精简
* **五子棋 UI 对齐**：棋盘绘制和推荐落子由“格子中心”调整为“网格交叉点”，与实际五子棋规则一致。
* **调试噪声控制**：关闭 PC 端每帧相机分辨率打印，保留关键性能日志。
* **SDK Demo 精简**：移除当前项目不需要的 RayNeo Demo 页面与资源，保留相机、TCP 推流和五子棋交互所需部分。

* **网络协议升级**：特别鸣谢贡献者 [JohnnyZhu035](https://github.com/JohnnyZhu035) 为本项目的 TCP 传输架构做出的贡献。推流方案已由 UDP 更改为更稳定的 TCP 传输。

## 历史更新信息 (8月3日)

本次更新主要上传了实现**雷鸟智能眼镜**向 **PC** 通过无线网络（Wi-Fi）进行实时视频推流的完整代码。采用了 UDP 传输方案，适合需要在 PC 端对第一人称视角画面进行计算机视觉处理的应用场景。

## 代码结构
本项目代码主要分为两大部分：

1. **智能眼镜端 (Android)**
   * 基于雷鸟官方现成 SDK 进行的源码微调。
   * 主要功能：调用眼镜端摄像头（支持切换彩色/黑白及分辨率），将 YUV 图像实时转换为 JPEG 字节流，并通过网络协议（支持 UDP/TCP）向局域网内的目标设备发送。
2. **PC 端 (Python)**
   * 用于接收视频流的 Python 脚本。
   * 主要功能：监听指定端口，接收眼镜端传来的视频流数据包，利用 OpenCV 实时解码与渲染画面，并进行相应的计算机视觉处理（如 YOLO 目标检测）。

## 使用指南

### 1. 前置准备
* 确保你的**雷鸟智能眼镜**与 **PC** 连接在**同一个局域网（同一 Wi-Fi）**下。
* 在 PC 端安装好 Python 及相关依赖（如 `opencv-python`, `numpy` 以及 YOLO 所需依赖）。
* 在 Python 代码及 Android 代码中，确保绑定的 `IP 地址` 和 `端口号`（如 9999）一致。

### 2. 运行步骤
1. **眼镜端部署**：将基于 SDK 修改好的 Android APP 直接导入/安装到雷鸟智能眼镜中。
2. **启动推流**：在智能眼镜中打开该 APP，并开启相机权限，此时眼镜已开始向外发送视频流。
3. **接收画面**：在 PC 端直接运行 Python 接收脚本，即可实时看到智能眼镜传输过来的第一人称画面及最新的实时识别结果。
