# Rayneo

本项目旨在为Rayneo智能眼镜开发一个具有简单功能的应用。

> **更新日期：** 8月3日

## 更新内容概述
本次更新主要上传了实现**雷鸟智能眼镜**向 **PC** 通过无线网络（Wi-Fi）进行实时视频推流的完整代码。采用了 UDP 传输方案，适合需要在 PC 端对第一人称视角画面进行计算机视觉处理的应用场景。

## 代码结构
本项目代码主要分为两大部分：

1. **智能眼镜端 (Android)**
   * 基于雷鸟官方现成 SDK 进行的源码微调。
   * 主要功能：调用眼镜端摄像头（支持切换彩色/黑白及分辨率），将 YUV 图像实时转换为 JPEG 字节流，并通过 UDP 协议向局域网内的目标设备发送。
2. **PC 端 (Python)**
   * 用于接收 UDP 广播包的 Python 脚本。
   * 主要功能：监听指定端口，接收眼镜端传来的视频流数据包，并利用 OpenCV 实时解码与渲染画面。

## 使用指南

### 1. 前置准备
* 确保你的**雷鸟智能眼镜**与 **PC** 连接在**同一个局域网（同一 Wi-Fi）**下。
* 在 PC 端安装好 Python 及相关依赖（如 `opencv-python`, `numpy`）。
* 在 Python 代码及 Android 代码中，确保绑定的 `IP 地址` 和 `端口号`（如 9999）一致。

### 2. 运行步骤
1. **眼镜端部署**：将基于 SDK 修改好的 Android APP 直接导入/安装到雷鸟智能眼镜中。
2. **启动推流**：在智能眼镜中打开该 APP，并开启相机权限，此时眼镜已开始向外发送视频流。
3. **接收画面**：在 PC 端直接运行 Python 接收脚本，即可实时看到智能眼镜传输过来的第一人称画面。

## 资源与依赖

---
*注：由于 UDP 单包大小存在 64KB 限制，若在使用过程中遇到画面卡顿或黑屏，请在眼镜端代码中适当调低图像分辨率或增加 JPEG 压缩率。*
